# 首版范围说明（Step 0.1）

## 1. 产品目标

首版交付一条可演示的个股研究链路：上传研究资料 → 解析入库 → 带引用问答 → 结构化摘要 → Agent 工具调用。

不追求功能大而全，先保证链路稳定、结果可追溯。

## 2. 首批文档类型

仅支持以下三类：

| 类型 | 说明 | 示例 |
|------|------|------|
| 财报 | 定期财务报告 | 年报、半年报、季报 |
| 公告 | 公司公开披露文件 | 重大事项、业绩预告 |
| 研报 | 券商或机构研究报告 | 深度报告、点评报告 |

## 3. 首批研究问题

| 问题类型 | 目标 |
|----------|------|
| 公司概况 | 业务、行业、基本画像 |
| 业绩变化 | 营收/利润变化及原因 |
| 风险因素 | 经营、财务、政策等风险 |
| 机构观点 | 研报一致点与分歧点 |

## 4. 首版明确不做

- 实时行情分析与技术指标策略
- 自动交易、下单、持仓管理
- 复杂投顾 / 资产配置建议
- 多市场全量爬虫与实时资讯流
- 完整用户体系（登录、权限、计费）

## 5. 首版验收标准

1. 能上传 PDF / DOCX / TXT / HTML 研究资料。
2. 文档能解析、切分并写入元数据与向量库。
3. 能按公司问答，并返回引用来源。
4. 能生成结构化研究摘要（极速 / 深度）。
5. Agent 能实际调用检索 / 摘要等工具，而非纯文本包装。
